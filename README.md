# 🏥 Hospital Management System

Hospital Management System is a Flutter-based application designed to provide a simple and user-friendly interface for managing hospital-related information such as doctors, patients, and appointments.

## 🚀 Features

* 👨‍⚕️ Doctors Management
* 🧑‍⚕️ Patient Management
* 📅 Appointment Management
* 🏥 Hospital Dashboard
* 📋 View and manage hospital information
* 🎨 Clean and responsive Flutter UI
* 📱 Cross-platform application design

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material UI**
* **Android Studio / VS Code**
* **Git & GitHub**

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/AbhishekKommu/hospital_management1.git
cd hospital_management1
```

### 2. Install Flutter Dependencies

```bash
flutter pub get
```

### 3. Run the Application

For Windows:

```bash
flutter run -d windows
```

For Chrome:

```bash
flutter run -d chrome
```

## 🎯 Project Objective

The objective of this project is to develop a simple hospital management application using Flutter. It focuses on creating a clean user interface for managing doctors, patients, and appointments in a single application.
